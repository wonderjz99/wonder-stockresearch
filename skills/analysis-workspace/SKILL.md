# 开放问题临时计算

适用于“近十年净利润增长率如何”“ROE 是否稳定”等不属于固定报告模板的数值问题。

1. 先检索已归档的富途和官方结构化记录，并检查期间、币种、会计准则和来源定位。
2. 优先运行项目的可信固定计算；它的公式、输入和来源会被保存。
3. 仅当固定计算不能回答问题时，导出最小数据集，再使用受限代码。代码只能处理该数据集，不能访问网络、环境变量、SQLite、项目文件或 shell。
4. 临时结果属于 InteractiveReport，不得修改正式 ResearchRun、评分、Gate、Moat 或 finish；用户明确保存 Memo 才能长期保存观察。
