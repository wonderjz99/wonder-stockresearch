# 护城河评分与资料补全

## 已归档资料能补什么

本项目已经归档的官网披露和富途结构化数据能够补强三家公司的主营构成、产品/地域收入拆分、长期收入与
ROE、现金流购置资产代理值、股东结构、管理层任职起点、分红与回购，以及部分用户规模和运营指标。它们
适合回答“公司有哪些业务、规模如何、资本投入与回报如何、治理和资本配置披露了什么”。

它们不能可靠替代同业单位成本、第三方品牌选择调查、真实客户迁移成本、流失率、许可清单或市场份额的
连续可比序列。因此这些问题保留 `gap`，不能因数据集存在就被自动标成已证实。

## 六项维度的固定含义

| 维度 | 判断重点 | 不可替代的证据缺口 |
| --- | --- | --- |
| M1 成本优势 | 相对单位成本、资源或工艺优势 | 同业可比成本结构 |
| M2 品牌与信誉 | 选择偏好、信任、定价能力 | 客户或第三方品牌资料 |
| M3 转换成本 | 工作流嵌入、合同、迁移成本与留存 | 实际切换/续约资料 |
| M4 网络效应 | 参与者增加如何提升其他参与者价值 | 生态机制或多边参与者指标 |
| M5 规模经济 | 规模如何摊薄固定投入或降低单位成本 | 规模与单位经济性的关系 |
| M6 监管与进入壁垒 | 牌照、频谱、自然垄断、准入 | 具体许可和续期条件 |

M1 不因用户数、网络覆盖或牌照而得到非空分数。M4 不因资产规模而成立，M6 不因治理结构而成立。相同
事实可以支持多项，但报告必须分别解释对应机制。

## 两个总分

严格证据总分只在六项均非 null 时计算。它回答“现有证据是否已足以为每一项护城河下判断”。

可用暂定总分始终给出：已评分维度使用原分数，null 维度在总分层面临时按 3 分计入，同时显示评分覆盖数、
null 维度和上下界。3 分是排序用的不确定性惩罚，并不是把未知维度评成 3 分；选择它而不是 5 分，是因为
5 分已经代表可见但有条件的护城河。新资料补齐后，该维度恢复由证据决定，暂定值自动退出。

例如四项已评分合计 24 分、两项 null 时：严格证据总分仍为 null；暂定总分为 30/60，区间为 24–44，
证据覆盖为 4/6。读者应优先比较严格分和覆盖度，再使用暂定分做需要单一数字的临时排序。
