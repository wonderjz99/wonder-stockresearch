# 公司研究规格 v1

这是 wonder-stockresearch 的自足业务契约。参考 moat Standard 公司分析框架，以中文重新组织；框架出处见 [provenance.md](provenance.md)。不需要访问旧项目才能实施。

## 1. 范围与报告命名

报告标题使用“公司研究 — Standard 公司部分”。保留原问题编号：Q01–Q24 为公司研究；Q25–Q28 为估值，当前明确 deferred。不能把暂未实现的估值四问伪装成已回答，不能把首版叫完整 28 问认证报告。

公司判断、证券价格与组合动作是不同对象。本版仅实现公司判断与原始市场数据；不生成建议加减仓、目标价或安全边际。报告可以提出补源、继续研究或等待验证。

## 2. 公司问题清单

| ID | 问题与应寻找的证据 |
| --- | --- |
| Q01 | 公司靠什么产品、客户和收费方式赚钱？用一段话讲清商业模式。 |
| Q02 | 行业近十年需求趋势如何？增长、稳定或收缩的证据是什么？ |
| Q03 | 业务多依赖资本投入？资本开支占收入的实际口径与覆盖期是什么？ |
| Q04 | 技术替代和产品变化有多快，会如何影响竞争地位？ |
| Q05 | 过去五至十年市场份额如何变化，口径是否可比？ |
| Q06 | 有无提价后仍保持客户与销量的证据？最近一次是什么？ |
| Q07 | 相比竞争者，单位成本或成本结构的优势体现在哪里？ |
| Q08 | 品牌能否被客户识别并影响选择？有哪些可验证材料？ |
| Q09 | 十年 ROE 是否持续高于 15%？覆盖不足时列实际年份；高杠杆和权益异常单独解释。 |
| Q10 | 维持现有盈利需要投入多少资本？披露、判断与未知项分开。 |
| Q11 | 自由现金流用于什么：再投资、并购、还债、分红或回购？ |
| Q12 | 债务与权益结构如何？在极端收入中断情景下有何生存压力？这是压力讨论，不把假设当预测。 |
| Q13 | 管理层持股和利益绑定如何？个人财富占比无公开依据时明确未知。 |
| Q14 | 管理层资本配置历史表现如何？至少检视具体成功与失败案例。 |
| Q15 | 管理层是否公开承认错误并采取纠正措施？引用具体披露。 |
| Q16 | 关键人员稳定性如何？未披露留任率时不估造比例。 |
| Q17 | 如果公司消失，客户会失去什么？替代是否容易？ |
| Q18 | 客户如何发现并购买产品？渠道、获客和分销结构是什么？ |
| Q19 | 客户留存、续约或重复购买表现如何？无量化披露时区分定性线索。 |
| Q20 | 产品对客户属于必要需求还是可选需求？衰退中有何证据？ |
| Q21 | 哪三类情景可能严重破坏业务？如果少于三类有依据，记录仍需调查的风险，不凭空编造。 |
| Q22 | 监管、牌照、定价和政策风险有哪些？ |
| Q23 | 客户、产品、地域的收入集中度如何？数值标明时期和口径。 |
| Q24 | 有无可能致命的杠杆、担保、表外义务或再融资依赖？ |

问题必须全部出现；每项可为 answered、partial 或 missing。partial/missing 都要说明缺什么、下一来源或检索方法、下一核验时点/触发事件、为什么会影响结论。十年数据难以取得并不允许虚构，也不要求无限检索。

## 3. 估值保留区（不实施）

Q25：市价相对 owner earnings 与历史水平。Q26：整家公司内在价值或愿付价格。Q27：市场与行业情绪。Q28：可比企业估值。

G4（价格合理性）也属于估值。首版报告结尾只标“估值部分尚未实现”，不输出四问的计算和通过状态。Q09 的财务质量阈值不是估值或买入规则。Q10/Q11 仍讨论公司现金创造与资本需求，但不实现维护性 OE 估算或 DCF；引用企业披露 FCF 时保留定义。

## 4. 公司门闸

| ID | 判断对象 |
| --- | --- |
| G1 | 是否能理解公司如何赚钱 |
| G2 | 是否有证据支持长期竞争力保持或增强 |
| G3 | 管理层诚信、利益一致性与资本配置可信度 |
| G5 | 盈利能力是否经过经济下行检验 |
| G6 | 是否能维持经营而不持续依赖外部融资 |
| G7 | 不利年份是否可能导致致命杠杆或偿付问题 |

每项为 pass / fail / insufficient，附推理摘要与证据引用。程序只展示结果及计数，不把通过数自动转换成购买、拒绝投资或固定复评日期。全部通过也不等于股票便宜。

## 5. 护城河评分

| ID | 维度 | 需要检查的关键证据 |
| --- | --- | --- |
| M1 | 成本优势 | 可持续单位成本优势、结构性资源或工艺优势 |
| M2 | 品牌与信誉 | 选择偏好、信任、可验证的定价能力 |
| M3 | 转换成本 | 迁移成本、客户工作流程依赖、留存与合同 |
| M4 | 网络效应 | 用户/参与者增加是否提高对其他参与者的价值 |
| M5 | 规模经济 | 规模增长是否持续降低成本或改善服务经济性 |
| M6 | 监管与进入壁垒 | 牌照、自然垄断、进入许可或难以复制的制度条件 |

各维度为 0–10 整数或 null；null 表示尚未评估，0 表示经证据评估未见优势，二者不可混用。模型给单项评分与依据，Python 加总。六项均非 null 时给总分 0–60，否则总分 null，不按已知项折算、不用组合乘数、不转百分制。

为减少不同会话漂移，以下为本版明确的实现默认锚点，不是用户新批准的投资阈值：0 无证据支持优势且有相反业务证据；1–3 局部/易复制；4–6 可见但有条件；7–8 持续且经验证；9–10 极强、长期且难以复制。锚点间具体整数仍是分析判断，必须解释。资料不足使用 null，不能用低分替代未知。

每个分数附 confidence（low/medium/high）、理由、支持与反方证据。相同事实可支持不同机制，但必须解释机制；M1 与 M5、M2 与定价能力不能只复制同一句理由。confidence 不作额外乘数。分数变化需有业务证据，股价/PE/PB 变化不能作为评分依据。

## 6. 来源与陈述

来源类别：primary（SEC/HKEX/IR/企业公开披露）、provider（富途）、secondary（新闻与检索线索）、legacy（旧研究）。类别只是来源属性，不是系统认证事实真伪。

来源保存 URL 或 provider endpoint、发布日期（允许 unknown）、真实获取时间、哈希、原文路径和提取状态。引用另附 locator：PDF 页码、网页提取行号/章节、或接口字段与报告期。

研究截止时点 as_of 使用带时区时间；已知在其后发布的材料不得进入本次研究。只有发布日期而无时分秒的材料，以对应市场当地日终作保守可用时点。日期完全未知的来源仅作背景，不独立支持核心结论；当时获取的 provider 快照不得冒充过去时点数据。

每个 Statement 分类为 fact / inference / assumption。fact 必须引用；inference 指向其依据；assumption 显式解释用途和不确定性。事实中的数值采用结构化 NumericFact：value、unit、currency（非货币可空）、period、口径与引用；避免将数值只藏在无法校验的正文中。

关键答案、门闸 pass/fail 以及非 null 评分，至少有一项可定位 primary/provider 支持。背景新闻可保留，但不独立支撑关键结论。程序只检查引用关系和元数据，不能声称验证了原文语义；分析者仍需读原文。

## 7. 反证、冲突与报告完成

每次研究记录最强相反观点、检索渠道与范围、找到的反方来源、哪些新证据可能推翻结论、下一验证点。没有找到反证时说明范围，禁止单独写“无”。

未解决的关键来源冲突阻止 finish；草稿可以保存。数据缺口本身不必阻止完成“带缺口的公司研究”，但受影响的门闸和评分应使用 insufficient/null，报告标 evidence_incomplete。

完成校验检查：所有问题/门闸/维度出现且无重复、有效数据类型、数值元数据、引用属于本 run、时间边界、原始文件存在、反证搜索记录、关键冲突、禁止估值混入公司评分。报告不包含未分类的任意自由正文，渲染使用固定结构。

完成仅表示记录通过结构与来源检查，不表示投资论点正确，也不表示原版 Standard 全部完成。

## 8. 复评

加载上次完成的公司研究和其来源摘要，再获取本次资料。旧来源保留真实首次获取与发布时间，引用到新 run 时显式关联；不改日期、不将旧结论自动升级为事实。

比较问题答案、门闸、评分、反证和缺口。程序列结构差异，模型解释变化原因并引用新旧材料。若研究口径或 schema 不同，显示不可直接比较，不伪造分差。缺分值时差值 null。没有新证据也可完成复评，但应明确“未取得足以改变判断的新证据”。

## 9. 报告层级与附记（用户 2026-09-18 决定）

公司报告分为三层，标准公司研究完成后不可修改：

1. **标准公司研究（季报级）**：本文件第 2、4、5 节的公司部分，标题“公司研究 — Standard 公司部分”。它对应一次完整研究，完成后冻结；需要更新时新开研究，不改旧正文。
2. **附记**：挂在某份已完成的标准研究之下，作为独立记录单独保存，不改标准研究正文。季度之间只按最新价格/资料重跑的小更新属于附记；**估值（Q25–Q28、G4）的产出位置也预留在附记**，但本版不实现估值内容，附记不得反向修改公司门闸或护城河分数。
3. **专题报告**：同行对比、新闻解读等非标准研究，单独成报，不要求 Q01–Q24 全覆盖，必须显著标注“非完整公司研究”。本版不实现，列入后续候选。

同一标准研究可以有多条附记，按挂靠关系归并展示；附记不覆盖标准研究，也不改变其来源、评分或完成状态。估值仍遵守第 1、3 节：公司证据决定公司判断，价格和估值不进入公司分数。
